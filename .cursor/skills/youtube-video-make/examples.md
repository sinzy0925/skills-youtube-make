# 使用例

## 例1: 最小入力（4項目すべて質問される）

**ユーザー入力:**
```
Cursorのスキル機能について動画にしたい

・スキルはSKILL.mdに書く
・エージェントが自動で読み込む
・個人用とプロジェクト用がある
・ざっとこんな感じで作れる
```

**エージェントの応答（Phase 0）:**
```
動画素材を作成します。以下を教えてください:

1. 形式: ぱらぱらマンガ型 / プレゼン型
2. 長さ・枚数の目安: 例「3分・8枚」
3. 画像スタイル: 例「フラットイラスト」「アニメ風」
4. 確認ポイント: A構成のみ / B構成+テキスト / C構成+テキスト+ナレーション / D全部自動
```

**ユーザー回答:**
```
プレゼン型、3分くらい、フラットイラスト、Bで
```

→ Phase 1 構成案を作成 → ユーザー確認 → Phase 3 確定テキスト → ユーザー確認 → Phase 4 ナレーション → Phase 5 画像 → Phase 6 パッケージ

---

## 例2: 形式指定あり（形式の質問をスキップ）

**ユーザー入力:**
```
マンガ型で、副業でプログラミングを始めた人の1日を描きたい。
朝起きてコードを書いて、昼はバグと格闘、夜に完成して喜ぶ流れ。
5分くらい。水彩風。全部自動で。
```

**エージェントの応答（Phase 0）:**
```
以下を確認しました:
- 形式: マンガ型（指定あり）
- 長さ: 5分 → 約15〜18コマを提案
- 画像スタイル: 水彩風
- 確認ポイント: D（全部自動）

進めます。
```

→ 質問なしで Phase 1 から開始

## 例3: 微修正フロー（確認ポイント B）

スライド3は「メリット」じゃなくて「こんな人におすすめ」に変えて。
